# Mac app (upstream Beamer)

This folder is Beamer's Mac app, kept as it is upstream so Beamer's fixes can still be merged
into Scotty. Scotty ships for Windows only and does not build or release this.

On a Mac, use [Beamer](https://github.com/kalkman-code/beamer): it pairs and works with
Scotty for the keyboard, pointer and clipboard (not files or head turn).
